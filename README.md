# Welcome to my Github page

I build software for machines that can't afford to be wrong.

Embedded software engineer working close to the hardware: bare-metal, firmware, FreeRTOS and Embedded Linux. C/C++ where memory and resource constraints are real, signal-level debugging with oscilloscope and logic analyzer when the code says it should work but doesn't, and Python and Bash for the tooling around it — test automation, device tooling, build scripts, data analysis.

Part of my role currently is enabling AI coding tools and testing them hard: behavioral regression, output quality, prompt injection, data leakage, and permission behavior.

## Where I'm heading

From writing systems to designing them — architecture, trade-offs, and asking the questions that should have been asked before the first line of code.

## Beyond the job

Powerlifter — and I build my own software for it. Linux enthusiast with receipts: CachyOS as my daily driver, a Docker home server, Raspberry Pi tinkering, kernel and driver hacking, and a rice I'll never stop tweaking. I also build my own AI skills and prompt-engineering tooling — engineering how I work with agents, not just prompting them.

## How I work

- **Requirements before code.** Spec and domain model before feature code; with two viable options I name the tradeoff, pick one and commit — and I'd rather be grilled upfront than agreed with politely after.
- **Simplest thing that works.** No speculative features, no abstractions until they've earned their keep; comments only for non-obvious whys, names carry the whats.
- **Curiosity-driven.** I take things apart — kernels, tools, my own workflow — and I ask why even when it already works.
